# 眠翼鸟（Sleepwing）

眠翼鸟是 Sleepwing 的品牌桌宠。名字沿用“月尾猫”的“特征 + 物种”结构：“眠”来自闭眼栖息时的安静陪伴感，“翼鸟”保留 Logo 最有辨识度的垂翼轮廓。它并不是一直闭眼；需要关注时，会睁开一双很大的眼睛。

## 角色设定

- 身份：Sleepwing 的安静守候者
- 性格：温和、专注、不打扰；发现你久等或工作过久时才会主动提醒
- 口吻：短句、具体、不制造焦虑
- 核心动作语言：平时闭眼栖息，需要关注时睁大双眼；长翼、喙和一长一短的脚共同表达状态

## 视觉规则

- 青绿色圆润身体、奶油色肚子、橙色小喙和脚是固定识别元素
- 正面必须有两只同高的眼睛；小喙始终位于两眼正下方，不能代替任意一只眼睛
- 睁眼时是两只明显的大号深青色椭圆眼，只有很小的暖色高光；闭眼时同步变成两条对称弧线
- 侧面只显示一只眼睛，并复现 Logo 中“眼睛在上、外轮廓小喙在下前方”的关系
- 眼睛开合时，喙、肚皮、翅膀、脚、身体中心和落脚基线不得漂移
- 翅膀自然下垂，轮廓像柔软的绒面玩具
- 身体保持低而宽，肚皮靠下且不过分突出，脚保留一短一长的栖息感；避免企鹅式高蛋形
- 不使用外发光、投影、速度线或脱离身体的装饰特效
- 所有动作保持相同的身体比例、落脚基线、材质与配色

## 状态与动作

| Sleepwing 状态 | 眠翼鸟动作 | 用户感知 |
| --- | --- | --- |
| 空闲 | 闭眼栖息、短暂睁大双眼、轻微呼吸 | 安静陪伴但保持感知 |
| 向右/向左移动 | 小步快跑，方向明确 | 可被拖动与重新停靠 |
| 打招呼 | 抬起一侧翅膀 | 友好出现 |
| 完成 | 向上跃起 | 克制地庆祝 |
| 失败 | 身体下沉、失落 | 任务受阻 |
| 等待 | 睁大双眼，长翼收拢护住肚皮 | 正在等你 |
| 工作中 | 睁大双眼，翼脚交替做专注动作 | AI 正在处理 |
| 复盘/提醒 | 大眼观察并抬翼示意 | 有值得查看的健康提醒 |
| 注视方向 | 16 向连续视线动作 | 跟随指针与注意目标 |
